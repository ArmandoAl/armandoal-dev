# Armando Alvarado — Portfolio

Bilingual static portfolio built with Astro. Production: https://armandoal-dev.vercel.app.

```sh
npm ci
npm run dev
npm run check
npm run build
```

Vercel deploys the repository root and serves `dist/`. Publish with `vercel --prod` using the linked `armandoal-dev` project. Firebase's optional hosting configuration also serves `dist/`.

Content lives in `src/content/`; downloadable CVs live in `public/cv/`. The HerNotes page embeds its hosted Flutter demo, independently of the portfolio framework.
